# 随行

随行是一款个人使用的 Android 辅助工具，用于日常使用比亚迪蓝牙钥匙和查看车况。

## 主要功能

- **蓝牙钥匙**　手动上锁和解锁，可按需开启走近解锁、离车上锁。
- **车况查看**　查看门锁、门窗、油量、电量和续航等车辆状态。
- **用车提醒**　支持离车锁态提醒、解锁后续航提醒和低油量提醒。
- **蓝牙调试**　校准走近和走远的信号阈值，查看信号波形和控车记录，导出诊断日志。
